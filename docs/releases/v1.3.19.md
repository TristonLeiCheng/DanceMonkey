# DanceMonkey v1.3.19

## 改进

- **今日工作台**：新增「今日」首页，聚合笔记、任务、会议、提醒与快捷入口；支持跳转到对应模块与会议详情
- **UI 设计系统**：抽出 `Themes/DesignTokens.xaml` 与 `Themes/Controls.xaml`，主界面侧栏分组与导航样式统一刷新
- **会议中心联动**：今日工作台可按会议 Id 打开会议中心工作台（`OpenMeetingById`）
- **笔记 / ZenTask / 提醒**：工作区投影、任务持久化协调与定时提醒服务同步增强，配套 UI 测试项目
- **发布脚本**：版本守卫与还原脚本小改进

## Improvements

- **Today workspace** home dashboard with navigation into notes, tasks, meetings, and reminders
- **UI design tokens** and control themes for a refreshed shell / sidebar
- **Meeting hub deep-link** from Today via meeting Id
- **Notes / ZenTask / reminders** persistence and projection updates, plus UI test project
- **Publish tooling** version guard and restore script tweaks

## 安装

1. 下载 `DanceMonkey-win-x64-1.3.19.zip`
2. 解压后运行 `DanceMonkey.exe`（升级会在当前目录就地替换）
3. 从网络盘启动请使用 **`启动 DanceMonkey.bat`**
4. 需 Windows 10/11 与 WebView2 运行时

## Install

1. Download `DanceMonkey-win-x64-1.3.19.zip`
2. Run `DanceMonkey.exe` (updates apply in the same folder)
3. Use **`启动 DanceMonkey.bat`** when launching from a UNC path
4. Windows 10/11 + WebView2 Runtime required
