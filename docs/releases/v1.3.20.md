# DanceMonkey v1.3.20

## 改进

- **会议中心生命周期工作区**：合并会议生命周期改版，工作台按会前 / 会中 / 会后流程重组导航与内容区
- **会议 Hub Web 页**：精简并重构 `meeting-hub.html` 交互与布局，配合 `MeetingHubService` 补充桥接能力
- **契约测试**：新增会议 Hub 生命周期相关 PowerShell 合同测试

## Improvements

- **Meeting lifecycle workspace**: merge prep / live / wrap-up oriented meeting hub redesign
- **Meeting hub Web UI**: streamlined `meeting-hub.html` with supporting bridge updates
- **Contract tests**: lifecycle checks for the meeting hub

## 安装

1. 下载 `DanceMonkey-win-x64-1.3.20.zip`
2. 解压后运行 `DanceMonkey.exe`（升级会在当前目录就地替换）
3. 从网络盘启动请使用 **`启动 DanceMonkey.bat`**
4. 需 Windows 10/11 与 WebView2 运行时

## Install

1. Download `DanceMonkey-win-x64-1.3.20.zip`
2. Run `DanceMonkey.exe` (updates apply in the same folder)
3. Use **`启动 DanceMonkey.bat`** when launching from a UNC path
4. Windows 10/11 + WebView2 Runtime required
