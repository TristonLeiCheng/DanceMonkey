# DanceMonkey 3.1.0

Windows x64 更新包：`DanceMonkey-win-x64-3.1.0.zip`。旧版客户端可通过 GitHub Latest 或本次 Release 附带的 `update-manifest.json` 检查更新。

本次更新：

- 项目里程碑、任务阶段进度、排序与关联任务安全转移。
- 独立的项目生命周期和健康度、每周进展记录，以及逾期、受阻、临近截止和久未更新提醒。
- 从笔记选段或全文批量生成项目任务，预览重复候选并保留来源链接；失败可回滚和重试。
- 增加桌面与预览数据测试、隔离真实知识库的 Electron 界面端到端测试。

验证：27 项单元测试与 Electron 界面端到端流程通过；Windows ZIP 从 macOS 交叉打包，未在 Windows 实机启动验证。更新包未做 Windows 代码签名。
