# DanceMonkey v3.10.0

## 笔记主页与快捷操作

- 进入笔记页面默认显示主页，避免自动打开模板文件；侧栏可随时返回主页。
- 一键创建空白笔记、普通笔记、日记、会议记录、项目和人物笔记，沿用已配置的知识库模板与目录。
- 展示当前笔记库的笔记总数、近七天创建和更新情况、占用空间，以及近期创建和更新的笔记。
- 提供标题、路径快速搜索与全文搜索入口；模板、隐藏文件和系统数据不计入个人笔记统计。
- 将笔记库切换、知识库配置和模板入口收纳到侧栏底部的折叠菜单，默认保持简洁。

## 点击解决同步冲突

- 同步预览直接列出冲突文件，可查看本地与远端内容，逐个选择或批量处理。
- 支持保留本地、保留远端、保留两份；Markdown 还可将两方内容合并到同一文件。合并按顺序保留两方文本，不做自动语义去重。
- 选择完成后先预览结果，再点击同步；执行前检查本地、远端是否变化，并保留本地备份。
- 文件删除冲突也可通过点击选择处理；任务和项目 JSON 使用整文件取舍，避免拼接破坏结构。

## 宠物键盘与桌面互动

- 宠物右键菜单新增“开启交互模式”：方向键行走、空格跳跃、Esc 退出；切换应用会自动退出，默认不开启。
- Mac 上可读取 Finder 桌面图标位置，让宠物靠近、跳上图标，并使用 E 键抱起或放下图标动画。
- 携带的是图标的视觉副本，不移动、删除或修改原文件。Finder 权限不可用时仍可行走与跳跃。
- Windows 保留键盘行走与跳跃；Finder 图标互动仅适用于 Mac。桌面叠放和自动排列不支持图标互动。
- 保留 v3.9.1 的19种宠物、像素外观优化、统一设置入口与宠物选择持久化修复。

## 下载

- Windows x64：`DanceMonkey-win-x64-3.10.0.zip`，解压后运行 `DanceMonkey.exe`；附带 `update-manifest.json`。
- Mac Apple Silicon：`DanceMonkey-mac-arm64-3.10.0.dmg` 或 `DanceMonkey-darwin-arm64-3.10.0.zip`。
- Mac Intel：`DanceMonkey-mac-x64-3.10.0.dmg` 或 `DanceMonkey-darwin-x64-3.10.0.zip`。
- 附带 `SHA256SUMS.txt`，用于校验安装包及更新清单。

- 491 项单元与集成测试通过，包括双客户端同步、修改/删除冲突、过期预览保护、失败恢复、笔记库隔离和宠物互动。
