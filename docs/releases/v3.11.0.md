# DanceMonkey v3.11.0

## 动画伙伴与自由活动

- 新增绒绒考拉、糯米小仓鼠、奶团小海豹、写实版大胃袋良子，以及仿真蟑螂和仿真蚊子；移除话务员兔子。当前共 24 种外形，包含 14 种动画伙伴和 10 种像素伙伴。
- 大胃袋良子采用经典黑底黄金花纹短袖，包含吃面、休息、招手和点赞等动作。
- 仿真蟑螂随机快爬、停步探路和转向；仿真蚊子曲线变速飞行，穿插悬停和落地休息。步态、振翅与方向随移动变化。
- 鼠标移到昆虫身上、拖动、打开菜单或显示提醒时暂停自由活动，保持在所在显示器的可用桌面范围；可在设置或宠物右键菜单关闭。
- 改进透明素材裁切、细触须和翅翼显示、高清屏缩放及气泡定位。保留像素伙伴的自然眨眼节奏，以及键盘行走、跳跃和 Mac 桌面图标互动。
- 宠物选择统一在设置卡片中完成，保存后立即应用；更新前校验当前角色素材，保留用户选择。旧版选择话务员兔子的用户可正常升级，升级后迁移到默认小人。

## 定时提醒与宠物举牌

- 新增定时提醒页面，管理喝水、久坐和自定义提醒，支持间隔、连续使用、每天多个时刻、每周、每月及一次性日程。
- 提供磨砂卡片、圆形、灵动岛、右下角 Toast、顶部横幅和紧凑胶囊六种弹窗样式；支持预览、稍后提醒、完成记录与导入导出。
- 可将通知方式设为宠物举牌：宠物缓步走到屏幕中央，放大并挥爪举牌，处理后返回原位；临时移动不覆盖保存位置。
- 多条提醒依次展示；宠物关闭、隐藏或正在手动交互时使用桌面弹窗。遵循系统减少动态效果，数据保存在本机。

## 主线功能整合

- 合并 v3.10.0 主线，包含笔记主页、六类笔记创建、近期列表、搜索、侧栏选项，以及点击处理 GitHub 同步冲突。
- 保留人物分身、六种名人 AI 示范、Outlook 导入、笔记库隔离、同步备份与过期预览保护。
- 同步集成更新器、退出保存、宠物设置持久化和发布资源校验的修复。

## 下载

- Windows x64：`DanceMonkey-win-x64-3.11.0.zip`，解压运行 `DanceMonkey.exe`；附带 `update-manifest.json`。
- Mac Apple Silicon：`DanceMonkey-mac-arm64-3.11.0.dmg` 或 `DanceMonkey-darwin-arm64-3.11.0.zip`。
- Mac Intel：`DanceMonkey-mac-x64-3.11.0.dmg` 或 `DanceMonkey-darwin-x64-3.11.0.zip`。
- 附带 `SHA256SUMS.txt`，用于校验安装包和更新清单。安装替换应用包，笔记和用户配置保存在应用包外。

## 验证

- 522 项单元与集成测试通过；补充的宠物迁移与更新器相关 42 项测试通过。
- Apple Silicon 打包应用验证通过：24 种宠物选择与保存、禁用/启用与重启、笔记主页六类创建与切库，以及六种提醒弹窗、真实到期完成/稍后提醒、宠物举牌与返回。
- 三个平台核对版本、123 个运行时文件、生产依赖和宠物图集哈希；Mac 应用签名与 DMG 完整性校验通过。
- 原生键盘行走、跳跃、边界、Mac 图标携带、Esc 和失焦退出，以及昆虫自由活动、动画帧、悬停/菜单/隐藏暂停与恢复验证通过。
- 打包后的宠物选择跨多次启动保留；未知角色选择及无关设置保存也保持原值。
