# DanceMonkey v3.12.0

- 将“宠物举牌提醒”统一命名为“宠物提醒”，保留行走、放大、展示提醒牌和返回动作。
- 页面顶部“默认提醒方式”下拉框加入“宠物提醒”，与六种桌面弹窗一起选择，默认使用宠物提醒。
- 新建提醒默认跟随全局通知方式；沿用旧版默认桌面弹窗的喝水、久坐提醒，在未单独覆盖样式时迁移为跟随默认；已明确指定的通知方式继续保留。
- 编辑单条提醒时可选择跟随默认、宠物提醒或桌面弹窗；单独指定的方式不受全局切换影响。
- 切换全局方式不重置日程、完成次数或稍后提醒；保留旧版数字枚举格式，迁移后单独指定的方式可跨重启保存。

## 下载与平台

- Windows x64：DanceMonkey-win-x64-3.12.0.zip；附带 update-manifest.json。
- Mac Apple Silicon：DanceMonkey-mac-arm64-3.12.0.dmg 或 DanceMonkey-darwin-arm64-3.12.0.zip。
- Mac Intel：DanceMonkey-mac-x64-3.12.0.dmg 或 DanceMonkey-darwin-x64-3.12.0.zip。
- 附带 SHA256SUMS.txt。Mac 采用 ad-hoc 签名，未做 Apple Developer ID 公证；Windows ZIP 未做代码签名。
- Windows 与 Mac Intel 为交叉构建，未在对应设备上完成运行验收。
