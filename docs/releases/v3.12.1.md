# DanceMonkey v3.12.1

补齐此前测试分支中遗漏的代理改进，提供 macOS / Windows 统一网络连接设置，并保留 v3.12.0 的全部现有功能。

- **网络连接**：支持直连、公司 / 系统默认和手动代理。手动代理支持固定 IP / 主机、端口、HTTP / HTTPS / SOCKS5、IPv4 / IPv6，以及可选的主机与网段直连例外。
- **连接范围**：应用默认用于 GitHub、Outlook 与更新；AI 可独立选择或跟随应用默认，人物分身和截图分析使用 AI 连接方式。旧配置默认 AI 直连，保留明确保存的选择，不改写公司系统 PAC。
- **连接测试**：可保存并测试 AI 连接、显示耗时、取消测试及刷新公司线路。PAC 支持声明的备用线路；固定代理失败不会擅自直连，已发送的请求不重复提交。证书验证保持开启，支持操作系统信任的企业证书。
- **配置修复**：补回旧字段迁移，防止旧代理、快捷键及更新字段覆盖新值；手动代理地址自动拆分并校验，重启后保留设置。
- **Windows 维护**：恢复系统代理快照、停用与退出恢复、外部修改保护、操作取消及恢复记录保留。Mac 使用统一应用代理设置，Windows 系统维护保留为高级选项。
- **补齐发布保护**：恢复交互模块哈希清单、缺失模块阻止打包以及自动准备发布文件的命令；核对 v3.12.0 运行文件基线。补回 Windows 暂不支持真实桌面图标交互的说明。
- **保留原功能**：24 款可选宠物、仿真昆虫自由移动、行走跳跃与 Mac 图标影像交互、气泡定位、默认宠物提醒及六种弹窗、笔记主页与冲突选择、人物分身、Outlook 导入、任务项目、截图、托盘及应用更新。

## 验证与平台说明

使用隔离配置、本地模型与本地代理验证网络和界面流程，不读取真实邮箱，不修改公司系统代理。包含真实 HTTP CONNECT、HTTPS 证书校验、SOCKS5 IPv6、Electron PAC 解析及备用线路、直连、重启配置保留和 v3.12.0 功能回归。

- 553 项自动测试通过，覆盖网络路由、旧配置迁移、Windows 代理恢复、宠物、提醒、笔记、任务、项目及同步。
- 设置与笔记保存/退出、AI、人物分身、Outlook、笔记主页、冲突选择、宠物行走/跳跃/抱图标、昆虫移动与动画渲染端到端测试通过。
- Mac Apple Silicon 包内代码通过真实 PAC / 固定代理 / 直连与重启测试；原生打包程序通过默认宠物提醒、六种弹窗、实际计时完成/稍后提醒和回退流程。
- 三个平台逐文件核对 125 个运行文件、24 款宠物、生产依赖、交互模块哈希与 v3.12.0 基线；Mac 签名、DMG 与 ZIP 完整性校验通过。

提供 Mac Apple Silicon、Mac Intel 与 Windows x64 安装包。Mac 使用 ad-hoc 签名，未做 Apple Developer ID 公证；Windows 包未签名，来自 Mac 交叉构建，Windows 实机注册表与交互效果仍需在 Windows 设备确认。
