# DanceMonkey v3.15.0

本次公开发布包含 3.13–3.15 本地体验版的 Markdown 编辑器改进。

- **本机 Markdown 编辑器**：笔记界面内直接编辑，可手动弹出独立窗口；通过系统关联打开本地 `.md` 文件时使用独立窗口。支持保存、撤销、查找、外部文件变动检测与退出前保存。
- **实时预览编辑**：标题、强调、列表等语法直接呈现格式并隐藏对应标记；保留源码、分栏和阅读模式，支持中文输入与 Windows CRLF 换行。
- **图片与表格**：实时模式显示图片和表格，提供图片属性及表格编辑操作。修复编辑区域背景与文字对比度。
- **图片导入**：在内嵌编辑器或独立窗口粘贴剪贴板图片、拖入本地图片，自动保存到文档旁的 `images/` 目录并插入相对路径。同名文件不会覆盖；导入后立即关闭或退出时会等待导入及文档保存完成。
- **编辑工具**：新增常用 Markdown 格式、链接、图片及表格工具，文档路径移至底部，打开本地 MD 的入口改为紧凑图标。
- **截图排错**：补充 macOS 屏幕录制权限检查、明确的失败对话框及系统设置入口；获取画面超时后释放状态并恢复窗口，截图时也隐藏独立文档窗口。修正 Mac 快捷键提示。

## 验证与平台说明

- 568 项自动测试通过。
- Markdown 编辑器端到端测试及 Mac Apple Silicon 打包版本测试通过，覆盖实时编辑、图片粘贴与拖入、相对路径预览、保存和关闭流程。
- 截图端到端测试通过，使用模拟屏幕画面验证截图处理、PNG 编码、系统剪贴板及粘贴进入 Markdown 文档；不能替代系统录屏权限授权后的真实屏幕采集验证。
- 本机实际截图诊断返回 `SCREEN_PERMISSION`。如果系统权限开关已开启但应用仍提示拒绝，可在「系统设置 → 隐私与安全性 → 录屏与系统录音」中移除旧条目，重新添加当前安装的 DanceMonkey 并授权，随后完全退出并重新启动。此权限须由用户确认。

提供 Mac Apple Silicon、Mac Intel 的 DMG / ZIP 与 Windows x64 ZIP，以及 Windows 更新清单和 SHA-256 校验值。Mac 使用 ad-hoc 签名，未做 Apple Developer ID 公证；本地签名随构建变化，系统授权可能需要重新确认。Windows 包未签名，由 Mac 交叉构建；Windows 与 Intel Mac 的实机体验仍需对应设备验证。
