# DanceMonkey v3.16.1

本次发布整合 3.16.0 本地预览版的笔记改进，并完成快速弹窗与分类保存。

- **快速笔记卡片**：改为紧凑的扁平卡片和小圆角，常用入口合并为单行工具栏。底部固定为「随手记」「会议要点」「临时想法」三个类型，切换时不再出现水平滚动条。
- **分类保存**：三类笔记分别保存到当前快捷笔记目录下同名的子文件夹。切换打开本类最近一篇，「＋」在当前类型新建；较早的笔记仍可通过搜索和完整笔记库查找。旧根目录笔记仍可读取，编辑时再归类。
- **修复重复新建**：连续输入和修改标题持续更新同一篇笔记；按序保存并保留较新的输入，切换、完成及退出前等待保存。分类、改名、重开和同名文件均保留稳定身份。
- **默认标题与提示**：新笔记标题采用「类型名称 + 本地日期」，直接聚焦正文。正文提示仅在空白时显示，输入后消失，不写入文件。
- **笔记外观与侧栏**：支持笔记及文件夹颜色、背景色和表情，改名后保留设置；文件树宽度可拖动或用键盘调整，并在重开后恢复。
- **元数据与双链**：内嵌及独立编辑器支持 YAML 元数据查看、编辑与自动保存，以及入链、出链与相关笔记跳转。保留正文、现有注释、BOM 和换行格式，无效 YAML 保留草稿并提示修复。

## 验证与平台说明

- 595 项自动测试全部通过，补齐元数据预览测试的模型依赖。
- 快速笔记与笔记主页源码端到端测试通过。
- Mac Apple Silicon 打包版通过快速笔记、笔记主页／外观／元数据／双链和独立 Markdown 编辑器端到端测试，覆盖分类文件夹、反复切换、同类新建、改标题、保存／重开、BOM／CRLF、侧栏宽度恢复与退出前保存。
- Mac 双架构和 Windows x64 包的 148 个运行文件均与当前源码一致；检查生产依赖、24 种宠物素材、既有功能文件、版本、架构、Mac 签名及 SHA-256。开发测试和设计核对文件不进入安装包。

提供 Mac Apple Silicon、Mac Intel 的 DMG / ZIP 与 Windows x64 ZIP，以及 Windows 更新清单和 SHA-256 校验值。Mac 沿用 ad-hoc 签名，未做 Apple Developer ID 公证；Windows 包未签名，由 Mac 交叉构建。Intel Mac 与 Windows 的实机体验仍需对应设备验证。

升级只替换应用，保留笔记库和用户配置。本地签名随构建变化，macOS 的录屏等系统权限可能需要重新确认。
