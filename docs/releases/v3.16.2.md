# DanceMonkey v3.16.2

本次发布合并自动更新修复、工作区外观设置和右上角笔记快速同步，同时包含此前本地 v3.16.1 的快速笔记与笔记库改进。

- **自动更新修复**：处理 macOS ZIP 解压残留的 AppleDouble 元数据，避免有效安装包被框架签名校验拒绝；修复路径别名导致新版本成功启动后仍回滚的问题。保留完整签名、版本、架构和宠物资源校验。
- **下载与错误反馈**：安装包改为流式下载，显示进度；网络中断自动重试，拒绝空包和不完整响应。区分下载、解压、校验及安装准备错误，保存本地更新日志，支持从设置页打开。暂存文件失效后可重新下载。
- **设置 → 外观**：主题、材质和透明度移出标题栏，集中到外观设置。提供 8 个主题选项（含跟随系统）、预设及自定义强调色、3 种材质、背景不透明度、13–20 px 阅读字号及恢复默认。即时预览、自动保存，并沿用已有偏好。
- **右上角快速同步**：同步图标直接准备变更并进入原有确认流程，显示忙碌、错误和最近同步状态；未配置或存在冲突时打开笔记同步设置。保留退出前保存、私有仓库检查、冲突处理和备份。
- **快速笔记与笔记库**：扁平卡片、小圆角；「随手记／会议要点／临时想法」分别存入独立子文件夹。修复每次输入重复创建笔记，新笔记使用类型加日期的标题和仅空白时显示的正文提示。包含笔记／文件夹颜色和表情、元数据、双向链接、侧栏宽度记忆及保存稳定性改进。

## 验证与平台
