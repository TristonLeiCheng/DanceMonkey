# DanceMonkey v3.16.3

- **后台同步**：右上角点击即可在后台同步。文件扫描、备份与 Git 处理移到独立线程，上传下载期间可继续编辑和切换页面；同步结果和冲突通过状态提示呈现。
- **保护编辑内容**：同步期间的新修改保留在本地，供下一次同步；待下载文件如有新的本地修改，会停止覆盖并保留双方内容及恢复记录。文件夹手动、定时同步也改为后台执行。
- **目录树滚动修复**：展开、折叠只更新目录列表，保留滚动位置和正文编辑器；刷新及切换页面后恢复对应笔记库的滚动位置。
- **弹出笔记窗口颜色修复**：独立 Markdown 窗口统一沿用工作区外观设置，修复玫瑰色等浅色主题下标题对比度不足的问题。

提供 Mac Apple Silicon / Intel 的 DMG 与自动更新 ZIP、Windows x64 ZIP，以及校验与更新清单。Mac 沿用 ad-hoc 签名，未进行 Apple Developer ID 公证；Windows 包未签名。Intel Mac 与 Windows 的验证范围为构建和静态完整性，实际运行验证在 Mac Apple Silicon 完成。

升级保留本机笔记和设置。本次为修复版，版本号 3.16.3。
