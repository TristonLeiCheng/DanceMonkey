# DanceMonkey v3.17.0

本次汇总 v3.16.3 之后的全部更新：项目工作台、项目与笔记 AI、小智机器人语音，以及对话和编辑数据保护。

- **项目工作台**：按概览、任务、里程碑、进展、资料和 AI 助手组织项目。完善任务状态筛选、完成进度、风险提示、归档与恢复；归档项目保持只读。
- **项目 AI 助手**：基于项目实时资料总结现状、检查风险、建议下一步和拆解任务；操作卡片确认后才写入，支持忽略和撤销。新增 AI 计划预览、跨项目提问、今日简报与宠物提示、周进展起草、人物分身审阅，以及将回答保存为项目关联笔记。
- **笔记 AI 助手**：围绕当前笔记及选区提问，可读取编辑器中尚未保存的内容。通过 `@` 明确引用其他笔记正文，回答保留来源。支持追加、替换选区或正文的修改预览、确认写回、撤销与重做；主界面和独立文档窗口均可使用。
- **持久对话与来源迁移**：笔记对话按笔记库和笔记保存，项目对话按笔记库和项目保存，重启可续聊。项目 AI 复用笔记引用能力，已选项、历史来源、复制和保存的回答保留来源链接。笔记或父文件夹重命名、同库移动后更新引用路径；重新打开项目或重启后仍能打开原来源。同一文件系统中的外部移动可按已记录的文件身份恢复，旧路径新建笔记不会串入原对话。
- **数据保护**：撤销前校验 AI 操作后的状态，拒绝覆盖后续人工修改；旧预览不能覆盖新编辑或磁盘上的外部修改。对话损坏、格式不兼容或迁移写盘失败时保留原文件，恢复后可重试。项目 AI 的 IPC 统一校验可信主窗口及主框架，切库后拒绝过期引用请求。受保护目录和敏感笔记不发送正文。
- **小智机器人语音**：新增独立机器人语音窗口，通过局域网 OTA 配对与 WebSocket 接入支持自定义 OTA 的小智固件，支持 Opus 音频、自动断句、字幕与语音播报。可选内网语音或 MGA，支持导入 CANON 配置、测试语音服务、设备发现和登记，以及设备支持的音量、亮度控制。可选启用笔记检索与确认后创建任务，凭据与普通笔记同步隔离。详见[接入说明](https://github.com/TristonLeiCheng/DanceMonkey/blob/v3.17.0/docs/xiaozhi-robot-voice.md)。
- **笔记与便签改进**：重命名时可选择目标文件夹，移动后保留外观及任务/项目关联；完善 PKB 快速便签路径与类型处理，兼容读取旧目录，修复保存和编辑冲突处理。

提供 Mac Apple Silicon / Intel 的 DMG 与自动更新 ZIP、Windows x64 ZIP，以及 SHA-256 校验和更新清单。Mac 沿用 ad-hoc 签名，未进行 Apple Developer ID 公证；Windows 包未签名。Intel Mac 与 Windows 的验证范围为构建和静态完整性，实际桌面运行及更新验证在 Mac Apple Silicon 完成。机器人语音以本机模拟服务和设备验证，不代表真实硬件与所有语音服务均已验收。

升级保留本机笔记、聊天记录和设置。对话记录保存在应用本地数据目录，不随笔记库同步；外部跨库、跨文件系统或文件身份已丢失的移动不自动匹配。

发布验证：731 项自动化测试全部通过；项目 AI、笔记 AI、快速便签、机器人语音和桌面基础流程通过隔离端到端测试。Mac 安装包通过真实更新、重启确认、旧包清理和笔记保留测试。三平台逐项核对 176 个运行文件、生产依赖、24 种宠物资源与 v3.16.3 功能基线，Mac 包通过严格签名校验。
