# DanceMonkey 3.2.0

Windows x64 更新包：`DanceMonkey-win-x64-3.2.0.zip`。旧版客户端可通过 GitHub Latest 或本次 Release 附带的 `update-manifest.json` 检查更新。

- 标题栏显示当前实际软件版本号。
- 最大化后工作区贴合窗口边缘，不再留下透明边框。
- 主题切换改为下拉选择，新增淡黄磨砂、淡绿磨砂、雾蓝与淡紫主题，并支持背景不透明度调整与持久保存。
- 修复更新器在 Windows 路径含空格时可能无法复制新版文件的问题。

注意：旧版本的更新器本身可能受路径空格问题影响。如果在线升级后仍打开旧版，请从本次 Release 下载 ZIP，解压到独立的新目录并运行其中的 `DanceMonkey.exe`；确认正常后再将桌面快捷方式指向该文件。
