# DanceMonkey 3.3.0

Windows x64 便携更新包：`DanceMonkey-win-x64-3.3.0.zip`。解压后运行其中的 `DanceMonkey.exe`；包内不含安装器或桌面快捷方式。

- 全新的 DanceMonkey「DM 粒子轨道」图标，统一 Windows 程序图标、macOS 应用图标和桌面快捷轨入口。
- 笔记文件夹展开状态会在重新打开后恢复；首次打开仅展开顶层文件夹。重命名或删除文件夹时同步维护记录。
- 笔记文件树的展开／收起按钮更清晰，并支持键盘操作。
- Windows 更新器在替换文件前校验包是否含 Electron 应用结构，避免误用不相关程序包。

已知调查项：有用户反馈运行解压包中的新版 EXE 后，会自动出现放在 OneDrive 桌面的早期火柴人程序。已审计 v3.2.0 官方发布包，未发现 Python 或旧程序文件；该现象尚未在本地复现，v3.3.0 的更新包校验不应视为对此现象的根因修复。若再次遇到，请提供实际运行的 EXE 完整路径与 SHA-256，以及旧程序进程的可执行文件路径。
