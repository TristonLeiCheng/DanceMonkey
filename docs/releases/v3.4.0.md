# DanceMonkey v3.4.0

## 新功能

- 新增 GitHub 私有笔记库手动同步，Windows / macOS 均无需安装系统 Git。
- 设置采用三步引导：GitHub 网页设备码授权 → 创建或选择笔记库 → 差异预览与确认同步。
- 预置 dmdesktop 的公开 App 标识；支持验证码复制、打开授权网页、GitHub 建库页面和授权仓库选择。
- 同步 Markdown、PNG、JPEG、GIF、WebP；支持跨设备修改与删除传播。
- 同文件冲突保留双方副本并停止同步；非快进推送拒绝覆盖其他设备的提交。
- 增加本地备份、未完成同步恢复、网络失败重试、路径与大小限制。

## 修复与改进

- Markdown 与快捷便签改用临时文件替换写入，减少不完整保存。
- 同步前等待编辑器保存，暂停写入；结束后刷新完整工作区与便签，防止旧缓存覆盖远端内容。
- 仓库选择与绑定状态更明确：点击“确认选择并进入同步”后解锁预览，预览成功后解锁确认同步。
- 未配置 GitHub App 时显示明确弹窗，而不是静默停留。
- Windows 打包统一使用 Forge，确保包含 Git 及其全部运行依赖。

## 下载与安装

- **Windows x64**：`DanceMonkey-win-x64-3.4.0.zip`，解压后运行 `DanceMonkey.exe`；附带 `update-manifest.json` 支持现有在线更新器。
- **macOS Apple Silicon**：`DanceMonkey-mac-arm64-3.4.0.dmg` 或对应 darwin-arm64 ZIP。
- **macOS Intel**：`DanceMonkey-mac-x64-3.4.0.dmg` 或对应 darwin-x64 ZIP。
- 将 macOS 应用拖到 Applications 替换旧版，笔记和应用配置不在应用包内，不随替换删除。
- 发布附带 `SHA256SUMS.txt`。

## 使用与限制

- 当前仅支持用户确认后的手动同步，不会连接后自动上传。
- 仅支持私有仓库；每个文件最多 10 MiB，同步范围最多 5000 个文件 / 200 MiB。
- 不同步任务/项目 JSON、API Key、软件设置、隐藏目录；遇到符号链接或大小写歧义会停止。
- 首版不支持直接更换已绑定仓库、分支或本地笔记库；使用专用仓库，避免与其他同步工具并发修改。
- GitHub 网页上创建仓库与授予 App 访问权限需用户分别确认；普通用户可用性取决于 App 拥有者设置的安装范围。
- 私有仓库不是端到端加密，删除当前文件不会清除 Git 历史。上传前检查笔记和截图隐私。
- 本地备份不自动清理，长期使用需留意磁盘空间。

## 验证与签名说明

- 本地自动化测试覆盖授权、仓库选择、双端同步、删除、冲突、并发推送及中断恢复。
- Electron UI 测试在隔离笔记库中执行，不访问真实 GitHub 或用户笔记。
- macOS 为 ad-hoc 签名，未做 Apple Developer ID 签名/公证；Windows ZIP 未做代码签名。
- Windows 与 Intel macOS 安装包为交叉构建，未在对应真实设备上完成运行验收。
