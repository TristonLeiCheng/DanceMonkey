# DanceMonkey v3.5.0

## 人物分身与人物档案

- 基于 MIT 许可的 Distilly 提示流程，导入文章、笔记或聊天记录，生成可编辑的人物卡。
- 每个人物独立聊天，支持来源引用、纠正、补充资料、更新和恢复历史卡片。
- 新增「人物档案」：手动记录出生年月（或完整日期）、星座、简历和事件；可仅用手动档案生成卡片。
- MBTI 可直接填写，也可由用户代填 12 道原创观察题计算倾向；未知或持平维度显示 X，结果可修改。这是简易观察记录，非官方 MBTI 测评或本人自评。
- 保存人物档案后可一键生成预览；确认保存后更新人物卡。保存名称、简介时保留未保存的档案草稿。

## Outlook 邮件导入

- 支持公司 Microsoft 365 全球云邮箱，以微软官方 MSAL 登录和 Graph 委托权限读取邮件。
- 连接自己的邮箱后，输入人物邮箱，搜索该人物来信、清理引用和签名、去重并生成卡片；支持后续手动更新。
- 仅查询登录用户有权访问的邮箱，不会仅凭邮箱地址读取对方的私人邮箱。首版不读取附件，不支持共享邮箱、个人 Outlook.com 或本地 Exchange。
- 每次检查最近 200 封匹配邮件，容量或更多邮件情况会提示；资料保存后生成失败可重试。
- 首次需注册微软桌面公共客户端，配置 `http://localhost` 回调和 Microsoft Graph **Mail.Read 委托权限**，在应用内填写租户 ID 与客户端 ID；无需客户端密钥。
- [微软应用配置与使用指南](https://github.com/TristonLeiCheng/DanceMonkey/blob/v3.5.0/electron-app/docs/outlook-setup.md)。

## 其他改进

- 新增多本地笔记库切换，分别保存目录展开状态；保存失败时阻止切库。
- 新增 PKB 基础目录初始化、笔记模板、本地全文搜索及保护目录同步检查。
- GitHub 私有笔记同步支持任务和项目数据，增加整文件冲突及关联检查。
- 改进 AI 对话布局、回复复制、失败重试、停止生成、滚动与截图流程。

## 下载与安装

- **Windows x64**：下载 `DanceMonkey-win-x64-3.5.0.zip`，解压运行 `DanceMonkey.exe`。附带 `update-manifest.json`，兼容现有更新器。
- **Mac Apple Silicon**：下载 `DanceMonkey-mac-arm64-3.5.0.dmg`，或对应 darwin-arm64 ZIP。
- **Mac Intel**：下载 `DanceMonkey-mac-x64-3.5.0.dmg`，或对应 darwin-x64 ZIP。
- Mac 将应用拖入 Applications 替换旧版；应用数据和笔记保存在应用包外。
- 发布附带 `SHA256SUMS.txt`，用于核对下载内容。

## 数据与验证说明

- 人物资料独立保存在本机，不随笔记库同步。生成和对话会向当前配置的 AI 服务发送所需资料；人物卡不是训练后的模型权重，模拟回答不代表本人真实表态。
- Outlook 登录缓存由系统安全存储加密，邮件正文作为人物资料保存在本机。
- 自动化验证使用临时目录和模拟外部服务，不发送真实笔记或邮件；真实 Microsoft 365 登录仍受公司应用审批和租户策略影响。
- macOS 采用 ad-hoc 签名，未做 Apple Developer ID 公证；Windows ZIP 未做代码签名。
- Windows x64 与 Mac Intel 安装包为交叉构建，未在对应真实设备上完成运行验收。
