# DanceMonkey v3.6.0

## 桌面宠物与「工程师」

- 恢复旧版 13 种像素宠物，保留物种专属台词、情绪变化和吃饭、睡觉、工作、阅读、运动等生活状态。
- 新增「工程师」狐狸外形，使用透明动画图集，支持待机、挥手、跳跃、等待、工作和阅读动画，以及高清屏平滑缩放。
- 支持单击互动、双击打开主界面、拖动保存位置、右键切换外形和大小，或打开 AI、笔记、待办与截图。
- 支持当前笔记库的任务气泡提醒、防休眠，以及 48 / 68 / 96 / 128 px 四种尺寸。
- 截图时暂时隐藏宠物，完成或失败后恢复；关闭宠物后释放动画计时器及防休眠。
- Windows 沿用旧版宠物配置；宠物位置独立保存，显示器变化时调整到可见区域。
- 工程师的生活动画沿用宠物模拟状态；本版尚未接入真实 AI 任务状态、自动行走或鼠标视线跟随。

## 设置选项卡

- 设置页按「快捷键」「桌面宠物」「笔记同步」「网络代理」「关于与更新」分组，macOS 隐藏 Windows 专用的网络代理页。
- 切换选项卡保留未保存的输入，支持方向键、Home / End 切换；保存失败后保留草稿。
- 快捷键、宠物和代理设置统一保存；GitHub 笔记同步和应用更新保留各自的操作按钮。
- 修正复选框和说明文字的对齐，改进小窗口布局。

## 更新、退出与桌面入口

- Windows 和 macOS 支持自动检查、后台准备更新，准备好后显示「更新并重启」。
- macOS 更新按本机架构选择 ZIP，校验应用版本、入口和签名，并在新版本启动失败时回退。
- 正常退出前等待笔记保存，停止同步、AI 和邮件导入；保存失败或超时会保留应用并提示。
- 增加 macOS 菜单栏、Dock 和 Windows 托盘入口，支持显示主界面、切换宠物和退出。
- 改进快速面板、AI 输入区域和更新提示的布局。

## 下载与安装

- **Windows x64**：下载 `DanceMonkey-win-x64-3.6.0.zip`，解压运行 `DanceMonkey.exe`。`update-manifest.json` 兼容现有 Windows 更新器。
- **Mac Apple Silicon**：下载 `DanceMonkey-mac-arm64-3.6.0.dmg`，或 `DanceMonkey-darwin-arm64-3.6.0.zip`。
- **Mac Intel**：下载 `DanceMonkey-mac-x64-3.6.0.dmg`，或 `DanceMonkey-darwin-x64-3.6.0.zip`。
- Mac 将应用拖入 Applications 替换旧版；笔记、配置和人物资料保存在应用包外。
- 附带 `SHA256SUMS.txt`，可核对安装包和更新清单的 SHA-256。
- 2026-10-23 重打包 Mac DMG，修复框架链接被改写为构建机绝对路径的问题，并增加镜像内应用签名校验。两种 Mac 架构的 ZIP 与 Windows 包保持不变；请使用更新后的 `SHA256SUMS.txt` 校验 DMG。

## 验证与已知范围

- 411 项单元与集成测试，以及工作区、宠物、AI、人物分身和 Outlook 端到端测试通过；验证使用临时目录及模拟外部服务。
- macOS Apple Silicon 打包后的应用已启动验证版本号、设置选项卡、工程师图集和正常退出。
- 真实工程师图集覆盖动画、尺寸、模拟 DPR 1/2、透明度、隐藏恢复与减少动态效果。动画帧率断言曾出现一次偶发失败，重跑通过。
- 截图隐藏和恢复已通过单测；真实剪贴板截图测试可能因系统剪贴板中不可物化的数据类型而在应用启动前失败。
- Windows x64 与 Mac Intel 安装包为交叉构建，未在对应真实设备上完成运行验收；跨显示器拖动尚未完成全部手动验收。
- macOS 使用 ad-hoc 签名，未做 Apple Developer ID 公证；Windows ZIP 未做代码签名。
