# DanceMonkey v3.7.0

## 新增：人物分身「名人示范」

- 新增孔子、老子、李白、爱因斯坦、乔布斯和马斯克六张示范卡，包含简短简介、不同的思考方式、表达风格和共 12 个开场问题。
- 点击「查看示范」先预览；取消不保存资料。「添加并开始对话」在本机保存可编辑人物卡与空会话，再进入既有对话界面。
- 开场问题只填入输入框，可修改后发送；预览和添加不调用 AI，点击发送才使用用户当前配置的 AI 服务。
- 按稳定示范标识去重，重复点击或重启后会打开已有分身；不覆盖同名用户人物，也不覆盖已有改名、资料、人物卡与聊天。删除后不会自动重建。
- 每张示范和对话界面均明确标注 AI 模拟，不是本人、官方账号或背书。风格是编辑设定，生成内容不是真实引语，不声称掌握私人思想或实时信息。
- 老子的生平与《道德经》成书年代保留争议说明；头像采用文字标识，无人物肖像下载或声音克隆。
- 沿用现有工作台外观，支持窄窗口排列和键盘焦点。

## 保留与兼容

- 保留 v3.6.0 已发布的「工程师」狐狸、13 种像素宠物、设置选项卡和应用内更新；本次不改变宠物实现和图集。
- 原有手动人物档案、资料导入、人物卡编辑与版本恢复、独立聊天、纠正和 Outlook 导入保持原有入口。
- 沿用现有 GitHub Releases 更新渠道，不修改 AI 模型、密钥或用户资料。

## 下载与签名

- Windows x64：`DanceMonkey-win-x64-3.7.0.zip` 和 `update-manifest.json`。
- Mac Apple Silicon：`DanceMonkey-mac-arm64-3.7.0.dmg` 和 `DanceMonkey-darwin-arm64-3.7.0.zip`。
- Mac Intel：`DanceMonkey-mac-x64-3.7.0.dmg` 和 `DanceMonkey-darwin-x64-3.7.0.zip`。
- `SHA256SUMS.txt` 覆盖上述安装包与更新清单。
- Mac 沿用 v3.6.0 的 ad-hoc 签名，未做 Apple Developer ID 公证；Windows ZIP 未做代码签名。下载或首次启动可能遇到系统安全提示，本版不绕过系统安全检查。

## 验证与已知范围

- 功能源码已通过 418 项单元与集成测试，以及人物分身和工程师狐狸的隔离 Electron 端到端测试。
- 验证覆盖六张卡、12 个开场问题、预览/取消、重复创建、用户编辑保留、聊天隔离、完整重启，以及原有导入、流式回答、停止、纠正和版本恢复。
- 测试使用临时用户目录与本地模拟 AI；没有验证真实模型的回答质量，也没有把生成回答当作名人的真实言论。
- Mac arm64 打包应用已完成上述人物分身端到端流程及完整重启验收；首次自动化连接曾超时，测试等待文件页面初始化后通过，未修改应用运行逻辑。
- 三个平台包内版本、架构和核心文件哈希已核对；Mac 代码签名严格校验通过。安装包排除开发测试目录，内容检查未发现用户配置、凭据或构建机个人路径。
- 当前仓库没有 GitHub Actions 工作流；构建与验收使用本地现有工具。
- Windows 与 Mac Intel 的真实设备运行验收仍需补充；工程师狐狸没有新增自动行走、鼠标视线跟随或真实 AI 状态联动。
