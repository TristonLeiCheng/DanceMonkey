# DanceMonkey v3.8.0

## 新增：原创话务员兔子桌面宠物

- 外形菜单新增独立的「话务员兔子」：奶油色长耳、青绿色带麦耳机、薄荷绿开衫与日常办公服。
- 包含九组、36帧透明 PNG 动画：待机、向右行走、向左行走、招手、开心跳跃、失落、倾听待命、耳麦通话、记录笔记。
- 点击互动播放招手，开心事件播放跳跃；工作、阅读和等待等原有模拟状态使用耳麦、笔记与倾听动作。短动作结束返回当前基础状态，周期广播不重播手势。
- 每帧使用独立裁切坐标，适配48/68/96/128尺寸和高DPI；新皮肤载入失败会明确提示，不显示其他动物冒充。
- 耳麦通话只是宠物模拟动画，没有真实电话或客服系统集成。左右行走素材提供于预览，未新增自动桌面游走。
- 本次只发布已经完成的九组动作，不包含接听、点头、打字、伸懒腰、庆祝五组额外动作。

## 保留与兼容

- 保留工程师狐狸、13种原版像素宠物，以及孔子、老子、李白、爱因斯坦、乔布斯和马斯克六位名人AI示范。
- 不自动切换用户当前宠物；不改人物档案、聊天、笔记或用户数据。名人示范仍为AI模拟，不是本人或背书。
- 继续使用现有GitHub Releases更新渠道。本次发布不自动替换当前已安装应用。

## 下载与签名

- Windows x64：`DanceMonkey-win-x64-3.8.0.zip` 与 `update-manifest.json`。
- Mac Apple Silicon：`DanceMonkey-mac-arm64-3.8.0.dmg` 与 `DanceMonkey-darwin-arm64-3.8.0.zip`。
- Mac Intel：`DanceMonkey-mac-x64-3.8.0.dmg` 与 `DanceMonkey-darwin-x64-3.8.0.zip`。
- `SHA256SUMS.txt` 覆盖五个安装包和更新清单。
- Mac采用ad-hoc签名，未做Apple Developer ID公证；Windows未做代码签名。系统可能显示安全提示，本版不绕过系统安全检查。

- 最终源码423项单元/集成测试全部通过；宠物真实Electron渲染与设置流程，以及六位人物示范回归均在隔离临时数据中验证。
