# DanceMonkey v3.9.0

## 新伙伴与动作素材

- 新增抱贝壳的小海獭、小熊猫咖啡师、团子小龙和绒绒兔，每只包含 9 组、36 帧透明动画及专属互动台词。
- 升级猫咪、狗狗和卡皮巴拉的动作素材；猫狗采用工程师风格，卡皮巴拉保留自然四足体态。
- 共 19 种外形：9 种动画伙伴、10 种像素伙伴。保留工程师狐狸、话务员兔子和既有点击互动、拖动、任务提醒与四种大小。

## 紧凑的实时预览

- 宠物设置改为紧凑、自适应的动画卡片，常规窗口约显示 5 列。
- 每张卡片都有独立动作按钮：洗脸、开贝壳、磨咖啡、练翅膀等可分别预览，不影响其他角色。
- 点击动作不会改变宠物选择；选中卡片并保存后才应用到桌面。
- 支持暂停、深浅背景、键盘选择、隐藏暂停与离开页面后清理资源。

## 修复更新与重启后恢复默认宠物

- 保留当前版本暂不支持的合法角色 ID，明确提示原选择已保留；保存其他设置不会改成默认外形。
- 右键菜单只写入本次修改的字段，避免旧快照覆盖刚保存的宠物选择。
- 打包时校验全部角色、图集尺寸与哈希，并生成素材清单；缺少或损坏素材会阻止打包。
- Mac 更新在准备和实际安装前检查候选包是否包含当前宠物，缺少该角色时保留现有版本和设置。
- 用户配置和笔记仍存放在应用包外，更新不替换用户数据目录。

## 下载

- Windows x64：`DanceMonkey-win-x64-3.9.0.zip`，解压运行 `DanceMonkey.exe`；附带兼容现有 Windows 更新器的 `update-manifest.json`。
- Mac Apple Silicon：`DanceMonkey-mac-arm64-3.9.0.dmg` 或 `DanceMonkey-darwin-arm64-3.9.0.zip`。
- Mac Intel：`DanceMonkey-mac-x64-3.9.0.dmg` 或 `DanceMonkey-darwin-x64-3.9.0.zip`。
- 附带 `SHA256SUMS.txt`，用于核对安装包与更新清单。

## 验证与范围

- 436 项单元与集成测试通过，包含设置保留、缺失角色更新拦截及素材完整性检查。
- Electron 设置回归验证卡片独立动作、保存、暂不支持的角色、重启恢复及原有互动流程。
- Mac Apple Silicon 打包应用使用隔离配置和进程内模拟钥匙串连续启动，验证海獭、暂不支持的角色与绒绒兔的选择保留；不改动真实笔记和配置，不宣称验证真实钥匙串授权流程。
- Mac Intel 与 Windows x64 为交叉构建，未在对应真实设备上完成运行验收。
- 保持现有签名方式：Mac 使用 ad-hoc 签名，未做 Apple Developer ID 公证；Windows ZIP 未做代码签名。
- 左右行走素材可在预览中查看，尚未新增自动桌面游走；工作、接听等为宠物模拟动画。
