# DanceMonkey v3.9.1

## 更可爱的像素伙伴

- 重绘小人、兔子、狐狸、大鹅、蟑螂、蚊子、青蛙、企鹅、乌龟和刺猬10位像素伙伴：圆润大头比例、细描边、柔和明暗、眼睛高光与脸颊细节。
- 增强粉色长耳、蓬松尾尖、透明翅膀、奶油围兜、分区龟壳与小刺等物种特征，细化吃饭、工作、阅读、运动和喝茶道具。
- 待机采用长停顿、轻微呼吸、小动作和短眨眼，减淡并固定落地阴影。桌面与设置卡片共用绘制和播放节奏，继续支持暂停、隐藏停绘、减少动态效果与48 / 68 / 96 / 128 px大小。
- 猫、狗和水豚的像素回退外形同步优化；共19种宠物及既有动画图集继续保留。
- 提供[动态预览与优化前后对比](https://github.com/TristonLeiCheng/DanceMonkey/blob/v3.9.1/electron-app/docs/pixel-pets-preview.html)源页面，可下载后本地查看。

## 统一宠物选择入口

- 移除宠物右键菜单中的“宠物外形”类型切换项。请在“软件设置 → 桌面宠物”中通过卡片预览、选择并保存。
- 右键菜单继续提供大小、防休眠、宠物设置及主界面、笔记、待办、截图等快捷功能。
- 同步更新设置页面说明及使用文档。已有宠物选择、大小与设置沿用v3.9.0的保留逻辑。

## 下载

- Windows x64：`DanceMonkey-win-x64-3.9.1.zip`，解压后运行 `DanceMonkey.exe`；附带兼容现有Windows更新器的 `update-manifest.json`。
- Mac Apple Silicon：`DanceMonkey-mac-arm64-3.9.1.dmg` 或 `DanceMonkey-darwin-arm64-3.9.1.zip`。
- Mac Intel：`DanceMonkey-mac-x64-3.9.1.dmg` 或 `DanceMonkey-darwin-x64-3.9.1.zip`。
- 附带 `SHA256SUMS.txt`，用于核对安装包与更新清单。

- 438项单元与集成测试通过，覆盖全部像素物种的九状态与四帧、短眨眼、透明背景、隐藏/恢复、减少动态效果、右键菜单入口和设置保留。
