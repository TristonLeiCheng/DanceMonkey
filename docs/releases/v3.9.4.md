# DanceMonkey v3.9.4

## 补齐完整宠物交互

修复v3.9.1发布基线遗漏本地交互代码的问题，将此前测试版本中的完整实现合入正式源码及安装包：

- 右键开启交互模式，使用 `←` / `→` 行走、空格跳跃、`Esc` 退出；失焦时停止输入并退出交互模式。
- Mac 可识别可见桌面图标，靠近、跳到图标顶部站立；按 `E` 播放抱起、携带与放下图标影像的动作，携带时可继续行走和跳跃。
- 补齐主进程接入、运动与碰撞、sandbox键盘桥接、图标读取、atlas动作、渲染、携带素材及清理逻辑。
- 保留10款像素宠物重绘、自然眨眼、紧凑动作预览、右键移除类型切换及宠物设置保留修复。19种外形与9套动画图集继续保留。

在“软件设置 → 桌面宠物”选择并保存宠物类型。右键菜单保留交互模式、大小、防休眠和原有快捷功能。

## 平台与范围

- 本次只提供与当前构建Mac对应的Apple Silicon arm64，以及Windows x64；不生成Mac Intel安装包。
- Mac桌面图标交互需要Finder自动化授权，图标需可见并采用支持的排列方式；抱起/放下为图标影像动画，不移动、打开或改写真实文件。
- Windows x64支持方向键行走和空格跳跃，真实桌面图标读取与交互尚未实现，界面会说明此限制。

## 打包完整性

- 生成交互能力清单，记录平台支持及11个关键模块/素材文件的SHA-256；缺少交互模块直接阻止打包。
- 新增 `npm run package:release:current`，只收集当前Mac架构与Windows x64的安装包，核对包内源码、交互能力、19种宠物素材及更新清单，生成独立版本目录与SHA256SUMS。
- Mac运行回归采用隔离配置、模拟桌面图标与进程内模拟钥匙串，覆盖行走、跳跃、图标落点、抱起/携带/放下、失焦退出、像素宠物、设置保存与重启保留；不读取真实用户桌面或笔记。
- Windows为交叉构建，未进行真实Windows设备运行验收。Mac沿用ad-hoc签名，未做Apple Developer ID公证；Windows ZIP未做代码签名。

## 下载

- Mac Apple Silicon：`DanceMonkey-mac-arm64-3.9.4.dmg` 或 `DanceMonkey-darwin-arm64-3.9.4.zip`。
- Windows x64：`DanceMonkey-win-x64-3.9.4.zip`，解压运行 `DanceMonkey.exe`。
- `update-manifest.json` 与 `SHA256SUMS.txt` 用于更新与完整性校验。
