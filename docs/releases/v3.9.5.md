# DanceMonkey v3.9.5 Windows x64 测试版

本次只提供 Windows x64 ZIP，用于验证 AI 网络连接修复与设置界面优化；尚未发布到 GitHub Release。

## AI 网络连接

- 新增“软件设置 → 网络连接”，AI 对话、人物分身和截图分析统一支持“直连／跟随系统”。默认跟随系统，保留旧版本连接行为。
- 直连使用独立连接池，绕过系统代理、PAC 与环境变量代理；跟随系统按 Electron 返回的 PAC 多条线路依序连接。
- 仅在建立连接失败、尚未发送请求时尝试 PAC 后续线路。没有声明 DIRECT 时不会擅自直连，不重放已发送的 AI 请求。
- 新增“保存并测试 AI 连接”，使用当前 API 配置发送一条简短测试请求；错误会显示在网络设置页。

## Windows 代理维护

- 将常用 AI 连接方式放在前面；系统代理自动维护、手动/PAC、备用 PAC 分层折叠。
- 手动地址接受主机、主机:端口或完整 HTTP 地址，自动拆分端口；支持 IPv6。
- 修复旧 PascalCase 配置字段覆盖新值，导致关闭后再次开启的问题。
- 开启维护前保存系统代理恢复记录，停用或退出时尝试恢复原配置；不覆盖其他软件已经修改的代理。
- 旧版遗留且没有恢复记录的系统代理不会自动清空；可选择 AI 直连，并通过“打开 Windows 代理设置”检查。
- 退出时取消未完成的代理操作；恢复失败保留记录供下次重试，避免阻塞退出。

## 宠物与设置保留

沿用 v3.9.4 的全部 19 款宠物、9 套图集、像素重绘、紧凑动作预览、行走与跳跃、移除右键切换类型及设置保留修复。Windows 真实桌面图标交互仍未实现。

更新时保留 Windows 用户数据目录，只替换程序文件；配置迁移保留宠物选择、大小、API、快捷键和其他现有设置。请完整解压新 ZIP 到程序文件夹后启动 DanceMonkey.exe，不要删除用户数据。

## 验证范围

自动测试覆盖配置迁移与重启保留、PAC 备用线路、直连隔离、取消、请求不重复发送、代理恢复与外部改动保护；端到端测试使用临时配置与本地 AI 服务。

Windows 包由 macOS 交叉构建，未在真实 Windows 设备验证注册表、PowerShell 或运行效果。ZIP 未做代码签名。
