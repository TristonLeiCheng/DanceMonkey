# DanceMonkey v3.9.6 网络连接统一测试版

统一 Windows / macOS 的 AI 网络设置，提供当前 Mac Apple Silicon arm64 与 Windows x64 测试包，未发布 GitHub Release。

## 公司 PAC 场景

- 未设置过 AI 连接方式的旧配置与全新配置，默认直连。AI 对话、人物分身、截图分析使用独立直连连接池，跳过系统代理、PAC 与代理环境变量。
- 公司开机重新下发 PAC 后，AI 的直连选择保持有效，无需每天关闭系统 PAC。
- 已明确保存的“跟随系统”或“直连”继续保留，不覆盖用户选择。需要代理访问模型服务时，可切回“跟随系统”。
- 两端均可在“软件设置 → 网络连接”中保存并测试 AI 连接；Mac 页面增加公司 PAC 说明。
- 此选项只影响本程序的 AI 请求，不改写企业 PAC、系统网络设置或其他软件的连接方式。GitHub、Outlook、更新等其他服务仍按既有系统规则连接。

## 保留的修复和功能

包含 v3.9.5 的旧代理字段迁移、PAC 备用线路、取消和错误提示修复，以及 Windows 自动维护停止后的代理恢复保护。保留 19 款宠物、像素重绘、紧凑动作预览、行走跳跃、移除右键宠物类型切换及现有设置。Mac 支持桌面图标影像交互；Windows 尚不支持真实桌面图标读取。

## 安装与测试

Mac 打开 DMG，将 DanceMonkey.app 替换到应用程序目录；Windows 完整解压 ZIP 后运行 DanceMonkey.exe。更新前退出旧程序，保留用户数据目录，宠物、API、笔记和其他设置继续使用。

若已保存为“跟随系统”，更新不会强行修改，请手动切换为“直连”，点击“保存并测试 AI 连接”。直连仍取决于模型服务在当前网络中可直接访问。

使用临时配置与本地模拟 PAC / AI 服务验证，不读取或改写真实公司 PAC。Windows 为交叉构建，需真实设备验证；Mac 为 ad-hoc 签名，未做 Apple Developer ID 公证；Windows ZIP 未签名。

## 本次验证结果

- 487 项自动测试通过，涵盖缺少网络字段的旧配置默认直连、显式选择保留、配置重启与宠物/API保留。
- 真实 Mac Electron 进程中配置隔离的模拟公司 PAC；AI 对话与连接测试未调用 PAC 解析，5 条本地请求符合预期。
- 设置页端到端测试通过，包括保存、草稿、笔记与退出流程。
- 两端安装包的 82 个第一方模块与当前源码逐一一致；19 款宠物、9 套图集和 11 个交互文件哈希通过。
- Mac 深度签名校验、DMG 验证、两端 ZIP 完整性及所有产物 SHA-256 通过；Windows EXE 为 x64 / 3.9.6.0。
