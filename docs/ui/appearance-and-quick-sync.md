# 外观设置与快捷笔记同步

主题、材质和透明度已从标题栏移入“设置 → 外观”。右上角保留紧凑的同步图标和外观设置入口。

- 8 个主题选项（包括跟随系统），8 个强调色及自定义颜色；背景材质、透明度、13–20 px 阅读字号和恢复默认。
- 修改即时应用、自动保存到本机；沿用原有主题、材质和透明度偏好。外观变化不重建笔记编辑器，跨窗口偏好变更和系统深浅色变化也会更新界面。
- 右上角同步图标会读取当前笔记库状态、预览变更并调用原有同步确认流程；未连接、未绑定或存在冲突时进入“设置 → 笔记同步”。保留编辑器保存握手、私有仓库检查、备份和冲突保护。
- 图标提供忙碌状态、重复点击保护、最近同步时间和错误提示；文件同步模块保持独立。

验证：607/607 单元测试；完整界面 E2E（外观设置、强调色、字号、透明度、设置草稿保留、未配置同步跳转）；源码及签名后的 arm64 完整应用均通过笔记主页、详情、主题、分栏、笔记库切换和重启 E2E。GitHub 同步测试使用模拟 API，未对用户仓库执行同步或上传。
