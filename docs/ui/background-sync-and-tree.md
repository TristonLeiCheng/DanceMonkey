# 后台同步与目录滚动

右上角同步按钮在笔记库已绑定时直接启动后台同步。按钮旁显示运行、完成或需要处理的状态；运行期间防止重复启动。未配置时进入同步设置；冲突和失败只留下提示，用户再次点击才打开详情。

GitHub 的扫描、哈希、备份与 Git 操作运行在工作线程。网络请求仍通过主进程已有的代理和超时策略，响应按块读取；凭据不会暴露给页面。预览只通知各编辑器保存草稿，不锁定窗口或重新渲染页面。仅在应用下载内容时短暂协调编辑器保存、阻止并发写入并刷新内容，随后恢复编辑位置。

上传使用本次预览的快照。期间的新修改保留在本地并提示再次同步。下载或删除前检查目标文件是否仍与快照一致；任务和项目数据作为关联文件一起检查。冲突时停止落盘，保留原文、备份和恢复记录。原有远端并发提交检查、私有仓库校验与同步范围限制继续生效。

手动和定时文件夹同步的扫描、复制也运行在工作线程，进度消息限频，取消通过共享标记传递。任务完成后仅更新当前显示的文件同步页面，不重绘其他页面。

笔记目录展开、折叠只替换目录行，保留滚动容器和正文编辑器。完整重绘时按笔记库记住本次会话的滚动位置，目录按钮重新聚焦时不自动滚动。

验证使用临时笔记库和本机 Git 仓库，不访问或同步真实远端笔记。覆盖后台线程运行时主线程响应、上传期间编辑、同文件冲突、取消、重复点击，以及长目录连续展开与刷新后的滚动保持。
