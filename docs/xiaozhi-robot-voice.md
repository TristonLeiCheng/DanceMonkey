# 小智接入 Dance Monkey

现有小智固件负责唤醒、麦克风、屏幕和扬声器。小智通过同一 Wi-Fi 的 WebSocket 把 Opus 音频送到运行 DM 的电脑；DM 转换录音、调用选定的语音服务，把字幕和 Opus 回传。电脑不使用麦克风。常用的按键录音和自动断句均受支持，单次录音最长 20 秒。

## 首次连接

1. 运行 Electron 桌面版，进入「软件设置 → 机器人语音 → 打开机器人语音」。开发版在 `electron-app` 目录运行 `npm run desktop`。
2. 点「导入 CANON 配置」，选择 CANON 的 `data/voice-profiles.json`。也可以在「连接与模型设置」手动填写。两套模式独立配置模型、音色和凭据。Mac 可在系统弹窗授权读取 CANON 对应的钥匙串项；凭据不会从 CANON 配置文件导出，也不发送给小智。可以在 DM 直接填新凭据，加密保存或只在本次运行使用。
3. 选择「内网本地语音」或「MGA 语音」，点击「测试当前语音服务」。测试先合成固定句子，再转写该合成音频，并发送固定问候给对话模型。内网模式默认验证 HTTPS，内网自签证书请选择可信 CA；macOS 提示访问本地网络时允许 DM。导入时不会继承关闭证书验证的设置。
4. 在网关里选择电脑当前 Wi-Fi 的 IPv4 地址，启动并复制 OTA 地址。把小智和电脑接入同一个可信 Wi-Fi。在小智的配网网页进入「高级」设置，把 **自定义 OTA 地址** 填成 DM 提供的完整地址，并保存重启。该地址包含配对凭据；请不要分享或将端口转发到公网。OTA 在此只下发 WebSocket 地址，不更新设备固件。
5. 唤醒小智或按其说话键。如果设备和电脑互相可达，DM 会显示已连接、收音、处理和播报状态。选择另一种语音服务后，在小智上重新唤醒即可；无需重新配网。关闭窗口后网关继续运行，退出 DM 后停止；重新打开 DM 需要再次启动网关。电脑 IP 和端口不变时，小智无需重新设置 OTA。

部分厂商版固件不显示「自定义 OTA」字段；只有支持自定义 OTA 并可接收 WebSocket 配置的小智固件才能按上述方式切换。需要先确认设备版本和板型再处理。未识别出 USB 串口时，请换支持数据的线或板子标有 USB/OTG 的接口，并允许 macOS 配件连接。正常使用语音不依赖 USB。

## 在 DM 查找和管理小智

「机器人语音 → 网络设备」提供：

- **查找设备**：读取本机当前网段的网络邻居，匹配已知设备 MAC，并解析小智设备名称。可填写完整 MAC 或 `Xiaozhi-xxxx.local` 进行定向查找；名字解析依赖网络 DNS/mDNS 支持。查找结果是候选设备，不代表已连接 DM。网络邻居最多检查 64 条，其中最多 32 条进行限时名称查询；没有遍历扫描整个公司网段。
- **自动登记**：小智访问 DM 的配网地址或建立语音连接后，记录 MAC、当前 IP、设备名称和最近接入时间。设备开启 MCP 时读取板型、固件与可用管理功能。配置中仅保存这些必要字段，不保存设备上报的 Wi-Fi 密码或完整系统信息。
- **管理**：重命名、移除离线记录、查看已连接/未连接状态；设备报告支持后可刷新设备状态、设置音量与亮度。通过小智 MCP 确认结果后才显示设置成功。设备断开或休眠后，控制入口停用，重新唤醒可恢复。
- **断开连接**：立即结束当前语音连接。设备下次唤醒仍可连接；“移除记录”仅删除 DM 中的历史记录，不撤销已有配网地址。

小智原固件通常主动连接服务器，并不提供通用的局域网发现/远程改服接口。未进入本机网络邻居缓存、没有可解析名称、休眠中或仍连接官方服务器的设备可能无法被查到。首次仍需在小智配网页填入 DM 的 OTA 地址。当前网关同时接收一台小智的语音连接。

## 语音与笔记

- **AI 问答：** 直接说问题。短对话历史只保存在当前小智连接内存中；断开设备或切换服务时清空。
- **查笔记：** 先开启「允许小智查询当前笔记库和新增任务」，然后说「查笔记 报价」或「在我的笔记里搜索项目复盘」。当前笔记库内按关键词查询，受保护目录和标记为敏感的 Markdown 不返回。标题和片段只发给小智屏幕，语音服务只合成命中数量。
- **新增任务：** 说「添加任务 明天发报价单」，看到任务预览后说「确认添加任务」或「取消」。可识别句首的今天、明天、后天及 ISO 日期。确认限时一分钟；切库、同步世代变化或断开后须重新发起。只有明确的语音指令能触发动作，模型的输出不能写入笔记库。

## 两套服务如何连接

- **内网本地语音：** 沿用 CANON 的分段接口，Mac 直连服务器并使用独立的 HTTPS 信任设置。默认接口依次为 `/v1/audio/transcriptions`、`/v1/chat/completions`、`/v1/audio/speech`。可编辑路径与模型。本地指的是配置的内网服务器。
- **MGA：** 沿用 CANON 的分段接口，Mac 使用公司/系统线路。能力探测为 `/api/v3/audio/capabilities`，分段转写、对话和合成分别为 `/api/v3/audio/transcriptions`、`/api/v2/chat/completions`、`/api/v3/audio/speech`。支持 CANON 的 Bearer 或 MGA API Token 等鉴权配置。CANON 实验性的 LiveKit 实时通话未用于此接入。
- **设备协议：** [小智官方 WebSocket 协议](https://github.com/78/xiaozhi-esp32/blob/main/docs/websocket_zh.md)；OTA 默认下发版本 1，网关也识别版本 2 和 3 的音频帧。普通对话没有自动改走另一家服务的行为。

运行 `npm test` 验证协议、切换取消和任务/笔记隔离。运行 `npm run test:e2e:robot-voice`，以本机 HTTPS 测试服务和模拟小智验证桌面设置、OTA 握手和音频往返，不调用真实语音服务。

## 本机开发板识别记录（2026-11-06）

通过 USB 的 esptool 查询与应用分区读取确认：ESP32-S3（QFN56 rev 0.2），内置 8 MB PSRAM、16 MB Flash，USB-Serial/JTAG 串口为 `/dev/cu.usbmodem1101`。当前有效启动分区为 `ota_0`，应用为 `xiaozhi 2.5.2`，构建时间 2026-10-11 19:21:58，ESP-IDF v6.1。

应用中的板型标识为 `esp32-s3-touch-amoled-2.16`，包含 Waveshare 对应驱动与自定义 OTA 配网页代码。识别过程读取了分区表、OTA 状态和应用镜像，并重启设备回到原固件；没有擦除或写入 Flash。USB 芯片/固件识别通过，尚不等于已经完成 Wi-Fi 网关配对和真实语音验收。
