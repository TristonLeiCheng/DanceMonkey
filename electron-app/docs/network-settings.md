# 网络连接设置

在 Windows 和 macOS 的“软件设置 → 网络连接”中选择并保存。未设置过时默认直连，已明确保存的选择在更新和重启后保留。

- **直连**：直接连接所配置的 AI 服务，忽略系统代理、PAC 和代理环境变量。适用于当前服务可直接访问、系统代理失效的情况。
- **跟随系统**：使用 Windows / macOS 当前代理规则。网络需要代理访问 AI 服务时使用。

公司开机下发或重新启用 PAC 后，已选直连的 AI 请求仍跳过系统代理，无需关闭系统 PAC。该选择仅影响 AI，不改写公司或其他软件的代理配置；其他服务仍使用原有规则。

“保存并测试 AI 连接”会保存页面配置，向当前 AI 服务发送一条简短请求，可能消耗少量 API 用量。请先在“API 与密钥设置”配置服务。

Windows“系统代理自动维护”为可选功能，会影响其他软件。展开后可选手动主机与端口或 PAC 脚本，设置维护间隔及绕过地址。备用 PAC 按钮会填入地址并启用维护，保存后生效。

停用维护或退出时，程序根据私有恢复记录恢复开启前的系统代理；发现其他软件改动则保留当前值。旧版没有恢复记录时不猜测和清空系统代理，可打开 Windows 代理设置手动检查。

旧代理字段迁移在读取默认值前执行，新字段优先；写入时清理旧别名。不会删除宠物、API、笔记及其他用户设置。网络方式对新请求生效，已开始的会话请求不切换线路。
