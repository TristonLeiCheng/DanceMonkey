# 网络连接（macOS / Windows）

入口：**软件设置 → 网络连接**。

应用默认连接用于 GitHub 笔记同步、Outlook 数据请求及应用更新。AI 对话、人物分身和截图分析可选择独立连接方式，或跟随应用默认。

| 方式 | 行为 |
| --- | --- |
| 直连 | 使用独立连接池，跳过系统代理、PAC 和代理环境变量。 |
| 公司 / 系统默认 | 由 Electron 读取当前系统代理与 PAC；不在 DM 中复制或硬编码公司地址。 |
| 手动代理 | 填写固定 IP 或主机、端口与 HTTP / HTTPS / SOCKS5 协议，支持 IPv4 / IPv6。 |

全新配置以及缺少连接字段的旧配置，AI 默认直连，其他服务默认跟随公司系统。已明确保存的连接方式继续保留。网络选项保存在本机，不会清除 API、宠物、提醒或笔记设置。

手动地址也接受 `192.168.1.100:8080`、`http://192.168.1.100:8080`、`[::1]:1080` 等形式；保存时拆分协议、主机与端口。地址不接受账号、密码或额外路径。可在直连例外中填写主机、IP、通配符、IP 网段或 `<local>`，例如 `localhost;127.*;10.0.0.0/8;*.company.example`。重定向会重新判断例外规则。

点击“保存并测试 AI 连接”，使用当前 API 配置发送一条简短请求，显示结果及耗时，可取消。模型端点、Key 或模型名称请在 AI 设置中填写。公司 PAC 变更后可点击“刷新公司 / 系统线路”；刷新不会中断已有请求。

连接失败不会擅自改变已选择的方式。公司 PAC 仅在连接建立失败且请求未发送时尝试其后续线路，不重复发送已提交的请求。证书验证始终启用，使用运行时标准根证书以及操作系统信任的企业根证书；未受信任的 HTTPS 代理会被拒绝。

上述三种方式只影响 DM 自身。外部浏览器登录使用浏览器的网络配置。Windows 的“系统代理自动维护”作为高级功能保留：开启前保存恢复记录，停用或退出时尝试恢复；其他软件已修改的配置不会被恢复操作覆盖。恢复失败保留记录供重试。macOS 不提供 Windows 注册表维护选项。

技术依据：[Electron Session](https://www.electronjs.org/docs/latest/api/session)、随项目安装的 Undici 7 文档（`ProxyAgent`、`Socks5ProxyAgent`）、[Node.js TLS](https://nodejs.org/api/tls.html#tlsgetcacertificatestype)。
