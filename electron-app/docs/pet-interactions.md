# 桌面宠物交互与打包核对

## 使用方法

1. 右键宠物，选择“开启交互模式”。
2. 用 `←` / `→` 行走，按空格跳跃；松开按键停止对应输入。
3. Mac 上可靠近可见的桌面文件/文件夹图标，跳到图标顶部站立，或靠近后按 `E` 抱起图标影像。
4. 抱着图标时仍可行走、跳跃；再按 `E` 播放放下动作。此过程不改变真实文件及桌面图标的位置。
5. 按 `Esc`、切换到其他应用或关闭交互模式退出。交互模式默认关闭，仅当前宠物窗口处理按键。

右键菜单保留“开启/关闭交互模式”，不再提供宠物类型切换；类型仍在“软件设置 → 桌面宠物”选择并保存。像素重绘、动作预览与既有宠物选择保留逻辑继续生效。

| 能力 | 本次 Mac Apple Silicon | Windows x64 |
| --- | --- | --- |
| 方向键行走、空格跳跃、Esc退出 | 支持 | 支持 |
| 可见桌面图标碰撞、站立 | 支持，需 Finder 自动化授权 | 尚未实现 |
| E键抱起、携带与放下桌面图标影像 | 支持，需可见且在触及范围内 | 尚未实现真实桌面图标读取 |

Mac 在桌面图标被遮挡、隐藏、采用叠放/自动排列或权限被拒绝时给出提示，并继续提供行走与跳跃。截图、任务和笔记等原有功能保留。读取桌面图标只在用户开启交互模式后启动；退出时取消读取并清理图像缓存。

## v3.9.1 遗漏原因与补包

v3.9.1 在发布工作树中整理了像素优化与菜单修改，但行走、跳跃、图标识别和携带功能仍只存在于主工作目录的未提交改动及本地测试包。正式发布基线未合入这些改动，导致素材存在而运行控制链路缺失。

v3.9.4 将此前已测试的完整实现合入正式源码：`desktop-pet.js`、`pet-motion.js`、`pet-carry.js`、`desktop-icons.js`、主进程接入、sandbox preload、atlas播放器、渲染器、样式、携带SVG及回归测试。保留v3.9.1的像素绘制、短眨眼、菜单移除和更完整的设置保留测试。

打包时在宠物清单中记录交互能力、平台支持和11个关键文件的SHA-256；任何交互文件缺失或为空都会拒绝打包。`npm run package:release:current` 只构建本机Mac架构与Windows x64，核对包内版本、交互能力、模块哈希、像素源码及19种宠物素材，并生成独立版本目录和校验文件。

验证包括控制服务/运动/图标/携带单元测试、设置保留回归，以及隔离测试中的原生窗口行走、跳跃、边缘、图标落点、携带与放下、Esc、失焦和像素宠物回归。`DM_PET_QA_APP_ROOT` 可指定打包后的 `app.asar`，直接验证包内控制器、preload、渲染器与素材；桌面图标采用测试夹具，不读取真实用户桌面，也不宣称完成真实Finder授权验收。
