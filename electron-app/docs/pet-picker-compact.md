# 紧凑宠物卡片与独立动作预览

宠物选择改为自适应紧凑网格：卡片通常190–260px宽，常规1280px窗口可显示约5列，减少大块留白。

每张卡片包含独立动作按钮：绒绒兔的眨眼、右蹦、左蹦、挥爪、蹦高、失落、打盹、洗脸、嗅嗅；海獭的开贝壳与看贝壳；小熊猫的磨咖啡与品咖啡；小龙的扑翼跳与练翅膀等。像素角色只展示其支持的6种状态。

动作按钮和选择按钮为平级控件，点击动作不改变宠物选择，不会触发保存。每张卡片有独立动作及播放起点，可以同时显示不同动作。保留统一暂停、深浅背景和可见区域内绘制；切换风格时保留各卡片的动作，离开设置时清理预览资源。

Electron设置端到端验证通过：独立动作同时播放、选择值不被动作按钮修改、帧序列播放、紧凑宽度、无嵌套按钮、暂停、键盘选择、切换选项卡、保存持久化和重启恢复。
