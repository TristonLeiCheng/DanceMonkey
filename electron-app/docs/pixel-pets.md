# 像素伙伴外形优化

设置里的10位像素伙伴（小人、兔子、狐狸、大鹅、蟑螂、蚊子、青蛙、企鹅、乌龟、刺猬）统一重绘为圆润的大头比例：单像素描边、柔和配色、顶部高光与底部暗面、眼睛高光、脸颊和物种细节。兔子保留长耳，狐狸有奶油色脸颊与尾尖，青蛙有鼓眼和笑脸，企鹅有奶油围兜，乌龟有分区龟壳，刺猬有错落的小刺。

绘制仍由 `src/pet-sprites.js` 生成32×32透明像素，桌面和设置卡片共用；48 / 68 / 96 / 128 px 尺寸继续使用像素缩放。猫、狗和水豚的像素回退也同步重绘，正常使用的动画图集不变。全部宠物ID与用户选择不变。

四帧待机改为2800ms循环：1400ms静止、560ms呼吸、700ms小动作、140ms眨眼。桌面和设置预览共用 `frameAt()`，支持暂停、隐藏停绘和减少动态效果。九种已有生活状态继续支持；吃饭、工作、阅读、运动、喝茶的道具同步细化，阴影减淡并固定在地面。

[动态预览与前后对比](pixel-pets-preview.html)支持9种状态、4档大小、深浅背景、暂停和优化前/后切换。旧版对比图集 `assets/pixel-pets-before.png` 从修改前的绘制代码导出，按状态分行、角色及四帧分列，不参与软件运行。

验证：`npm test`，包含所有像素物种的九状态与四帧、透明背景、眨眼时序、桌面隐藏/恢复、减少动态效果，以及原有设置保留和菜单回归。预览另经浏览器检查深浅背景、48px和128px显示及前后切换。

该优化随正式版 v3.9.1 发布。Mac Apple Silicon、Mac Intel 和 Windows x64 安装包共用同一套像素绘制与预览逻辑。
