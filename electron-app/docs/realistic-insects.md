# 仿真蟑螂与仿真蚊子

在「设置 → 桌面宠物 → 动画伙伴」前两张卡片中选择，点击保存应用。也可从桌面宠物右键菜单切换。

两个新角色分别使用 `realistic-cockroach`、`realistic-mosquito`，原像素蟑螂与蚊子继续保留。当前共 24 种角色：14 种动画伙伴、10 种像素伙伴。

## 形象和动作

- 仿真蟑螂：栗褐色翅鞘、细长触须、带刺步足；摆触须、右爬、左爬、抬前足、窜动、伏低、静伏、梳触须和探路。
- 仿真蚊子：细长腹部、长足、口器和半透明翅翼；悬停、右飞、左飞、抬前足、上飞、缓降、落地、梳理和警觉。

每只 9 组动作，每组 4 帧，总计 72 帧。休闲与睡眠状态使用休息动作，忙碌使用梳理，专注使用警觉。保留原有互动、键盘控制、文件搬运和提醒能力。

索引脚本保留原图，使用较低 alpha 阈值记录透明翅翼和触须，并合并单个细肢体内部的小间隙。逐帧验证透明间隔、四列九行、源图边界及逻辑画布边界。预览、桌面与提醒共用图集。

## 自由活动

默认开启，仅应用于仿真蟑螂和仿真蚊子。在设置中取消“仿真昆虫自由爬行 / 飞行”，或在宠物右键菜单取消“自由爬行 / 飞行”，即可关闭。

蟑螂采用短距离加速爬行、减速停顿、梳触须和转向探路；蚊子采用曲线变速飞行、快速振翅、短暂悬停和落地休息。步态速度随移动速度变化，身体随转向倾斜，转动后的触须和细腿保持在画布内。

活动限制在所在显示器的可用桌面范围。鼠标移到宠物/气泡上、拖动、菜单、气泡和提醒期间暂停；手动交互优先，退出后恢复自由活动。隐藏窗口暂停，遵循系统“减少动态效果”。自动移动不抢键盘焦点，不读取桌面图标，不持续改写保存位置；手动拖动仍会保存位置。

实现位于 `electron/pet-roaming.js`，以独立运动状态管理路线、速度和动作。随机性可注入以便验证，时间步长有上限，避免睡眠恢复或卡顿后突然跃迁。

本次自由活动更新：70 项相关测试通过；`npm run test:e2e:pet` 与 `node test/e2e-pet-control.mjs` 通过。后者直接测量原生窗口的移动位置，验证横纵移动、动作帧、悬停暂停、菜单暂停、系统减少动态效果、隐藏恢复、关闭/恢复活动与配置保持。[真实运行轨迹样本](realistic-insects-roaming-evidence.json)。
